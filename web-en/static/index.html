Responsible entity resolution

Explainable, fairness-aware matching — one micro-batch at a time

X-TREATS resolves entities arriving from two data streams under a time budget τ. Each increment is matched by a neural matcher, re-ranked to keep sensitive groups balanced, and justified with attribute-level explanations whose Explanation Score also guides the final ranking.

  1. StreamMicro-batches sent every τ seconds (Kafka)
  2. ComparisonDitto scores each candidate pair
  3. Fair rankingRound-robin across sensitive groups
  4. ExplanationLEMON or SHAP → Explanation Score
  5. AggregationGlobal top-k, one-to-one matches
Fairness

Bias@k, PPVP and TPRP compare sensitive groups after every increment.

Explainability

Attribute and potential scores are combined into a pair-level Explanation Score.

Streaming

Real-clock micro-batches; queue delay is reported when an increment exceeds τ.

      Expected file formats
      
    
        
  • Dataset (.txt) — one labeled pair per line, three tab-separated fields:
          left entity ⇥ right entity ⇥ label (1 = same real-world entity, 0 = different).
    • 
        
  • Each entity is a list of COL <attribute> VAL <value>. Both sides must have the same attributes, in the same order.
    • 
        
  • Attribute names: letters, digits and _ only (no spaces). The first attribute identifies the record (e.g. title) and cannot be empty.
    • 
        
  • UTF-8 text, at least 20 pairs, at least one pair with label 1. Same layout as data/er_magellan/Structured/<name>/test.txt.
    • 
        
  • Model (.pt) — a PyTorch checkpoint saved by Ditto's training (a dict with the key model, like checkpoints/Structured/<name>/model.pt), trained with the language model you pick below.
    • 
      

      
COL title VAL sony sound forge 8 COL maker VAL sony COL price VAL 59.99 ⇥ COL title VAL sound forge audio studio 8 COL maker VAL sony media COL price VAL 54.95 ⇥ 1

    


    

      

      

      
      

        
        
      

      Train/validation files are only used to build Ditto's TF-IDF summarizer index. If omitted, the dataset file is used.

      

      

        
        
      

      The language model must be the one used to train the checkpoint. The threshold is the score above which the model calls a pair a match (the built-in datasets use 0.1–0.6).

      

        Fairness groups
        

          
          
        

        
Each keyword defines one sensitive group: a value (or part of a value) of the chosen attribute that identifies the entities you want to treat as a group — e.g. the manufacturers microsoft, sony, apple or the categories printers, laptops. Separate keywords with commas. A pair joins the first group whose keyword appears (case-insensitive) in that attribute of either entity; everything else is group “others”. Bias@k, PPVP and TPRP compare these groups.
